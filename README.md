# AI Powered Resume Tailor 

An intelligent resume tailoring tool built with **Next.js**. Users input their resume and a job description, and the app generates a customized resume aligned with the job requirements using AI.

To run the development server
_npm run dev_

Or http://localhost:3000/

## Features

- Paste resume and job description
- Tailored resume generated with AI logic
- Clean and modern UI with **Tailwind CSS**
- Serverless API endpoints using **Next.js App Router**
- Deployed on **Vercel**
